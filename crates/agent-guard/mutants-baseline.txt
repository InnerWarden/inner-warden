# Known survivors of the weekly mutation sweep of the screening engine.
#
# One line per surviving mutant: file<TAB>function<TAB>mutation<TAB>why.
# The key is the first three fields, without line and column, so an edit above
# a survivor does not turn it into a new one. The same mutation can survive
# more than once in one function; it is then listed that many times. Generate
# keys with `scripts/mutants-baseline-check.sh --keys <mutants.out>`, never by
# hand, so the list and the check cannot key a mutant differently.
#
# `why` is one of:
#   not killed yet (sweep <date>)             a line the tests do not check yet
#   not killed yet (sweep <date>, timed out)  ran past three times the
#                                             unmutated suite: unseen, or a hang
#   equivalent: <reason>                      no input can tell it from the
#                                             original, and the reason says why
#
# The full sweep in .github/workflows/nightly-deep.yml fails a shard on a
# survivor that is not here (scripts/mutants-baseline-check.sh). A test that
# kills a mutant deletes its line in the same commit. Never add a line to make
# a shard green unless the mutant is equivalent: a new survivor is a line the
# tests do not check, and the answer is a test.
#
# Generated from the sweep of 2026-11-11 (run 43020449252, all forty shards),
# the first of the tree that holds guard 1.6.12: 5,223 mutants. The list
# before this one described the 4,372 mutants of the code before 1.6.12 (two
# sweeps on 2026-11-09, run 42634801508 and run 42699554438). This one is
# regenerated, not appended to: every line is a mutant this sweep saw
# survive, and a line keeps the date and the reason it had when the earlier
# list held the same key. An `equivalent:` reason written for a function that
# 1.6.12 rewrote is not kept: it describes code that is gone.
#
# The run reported as caught 76 mutants on which one test alone had failed: a
# time ceiling that 1.6.12 added in tests/guard_lowering_parse.rs, at 3.0 to
# 4.9 s for its longest line against a ceiling of 3 s. That is a busy runner,
# not the mutated line, and cargo runs no later test binary once one fails.
# The ceiling now reads IW_NO_WALL_CLOCK_CEILINGS like the others (see the
# workflow), and the 76 were run again with it off: 68 survive, 1 times out,
# 7 are caught by a test. They are listed as that run found them.
#
# 1,200 survivors: 1,034 missed and 166 timeouts. The other 4,023 mutants:
# 3,915 caught, 108 unviable.
