# Popular package names the typosquat check measures install names against.
#
# A name ONE edit away from an entry here (a letter added, dropped, changed or
# two adjacent letters swapped) that is not itself listed is surfaced for
# review: `pip install reqeusts`, `npm install expresss`. That is how
# typosquatted packages, and package names an AI agent invented, get installed.
#
# Two rules keep this list honest:
# - A real package that sits one edit from a popular one belongs HERE too
#   (scipy and scapy, react and preact, eslint and tslint), so installing it is
#   an exact match and never a look-alike.
# - Names shorter than five characters are never compared (one edit from `pg`,
#   `ws` or `six` is half the registry), so listing them only documents intent.
#
# PyPI names are compared in their normalised form (PEP 503: lower case, runs
# of `-`, `_` and `.` become `-`). Sections: [pypi] and [npm].
