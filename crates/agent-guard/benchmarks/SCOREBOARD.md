# Agent-Guard Proof Scoreboard (spec 079 P1)

Finite baseline of the structural command analyzer and embedded ATR inspectors against a 204-case corpus, routed by each case's declared surface. Generated by `cargo run -p innerwarden-agent-guard --example agent_attack_benchmark`.

`user_input` cases exercise the library inspection entry point; they do not assert that every installed agent adapter can observe prompts. The score is a regression result for these cases, not adapter coverage.
