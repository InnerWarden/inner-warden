# Agent-Guard Proof Scoreboard (spec 079 P1)

Finite baseline of the structural command analyzer and embedded ATR inspectors against a 405-case corpus, routed by each case's declared surface. Generated by `cargo run -p innerwarden-agent-guard --example agent_attack_benchmark`.

`user_input` cases exercise the library inspection entry point; they do not assert that every installed agent adapter can observe prompts. The score is a regression result for these cases, not adapter coverage.

Read **blocked for an agent** as the enforcement number, not the catch rate. Catch counts `review` as caught, which answers "was it surfaced" and cannot answer "was it stopped": a change that moved 54 cases from hard-deny to review left catch at 100% while enforcement halved. Hard-deny is reported separately and is expected to be BELOW the catch rate, because an unreviewed fetch-and-execute over TLS from a named host is not distinguishable from a vendor install line by its shape, and is enforced by policy rather than by pretending the engine can tell them apart.

The benign control set includes documented vendor install one-liners (`benign_install`). It previously held none, so the false-positive rate was computed over a set that excluded the shape the rules were most aggressive about; a rule denying every install line on earth scored 0%.
