# Security Policy

We take the security of InnerWarden seriously and appreciate reports
that help us keep users safe.

## Reporting a vulnerability

Please report suspected vulnerabilities privately, by email, to
**security@innerwarden.com**. Do not open a public issue for a security report.

Include as much of the following as you can:

- A description of the issue and its impact.
- Steps to reproduce, or a proof of concept.
- The version affected and your operating system.

## Supported versions

Security fixes are provided for the current 1.x release line.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## What to expect

- We aim to acknowledge your report within 3 business days.
- We will keep you informed as we investigate and work on a fix.
- Once a fix is released, we are happy to credit you if you would like.

Please give us reasonable time to address an issue before any public disclosure.
